# flora-shop

Сайт цветочного магазина «Флора» в Казани.

## Что использовал
- HTML: семантическая верстка, якоря для навигации, формы, карточки
- CSS: Flexbox для сеток (шапка, карточки, преимущества)
- CSS: эффекты при наведении (`:hover`), тени, скругления, псевдоэлементы (`::before`)
- CSS: `position: sticky` для закрепленной шапки, плавная прокрутка (`scroll-behavior`)

## Особенности проекта
- Главный экран с фоновым изображением и тенью текста
- Каталог с карточками букетов
- Блок преимуществ с иконками (псевдоэлементы)
- Форма заказа с выпадающим списком
- Адаптивная верстка
